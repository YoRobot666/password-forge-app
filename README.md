# Password Forge App

A lightweight, offline password generator built with Python and Tkinter.

No tracking. No cloud. Everything runs locally.

## Features
- Generate strong random passwords
- Customizable length and character sets
- Copy to clipboard in one click
- Clean dark UI
- Works offline

## Run from source
pip install customtkinter
python PWD_WGEN.py

## Build EXE
pip install pyinstaller
pyinstaller --onefile --windowed PWD_WGEN.py
